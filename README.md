Hello, welcome to the Github for my Player Dashboard!

This was a project I created in transition between graduate school and employment highlighting 
my ability to build a dashboard using Python (streamlit package specifically) incorporating things
like Scouting grades and other production metrics. Using this information, we want to find the right
type of profile to aid in roster management. I implemented a scouting strategy/forecasting of college
prospects likely to enter the transfer portal, achieving a 70% hit rate.
